# One Emoji, One Dream Vacation

Entry for the make.fun bounty [One Emoji, One Dream Vacation](https://make.fun/bounty/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35).

One emoji: the dream vacation as a single postcard.

> 🏝

`main.ts` writes the emoji to `/output/entry.txt`, after validating it (1 to 8 characters, exactly one emoji, not only white space). Both runs write identical bytes.
